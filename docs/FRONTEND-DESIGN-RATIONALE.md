# FRONTEND DESIGN RATIONALE

Civora helps public-policy teams understand whether a bounded official statistic remained stable, was revised, or became unsafe to use. The public landing layer therefore explains provenance, validator consensus, revision states and limitations before presenting any wallet action. Its primary navigation is Overview, How it works, Documentation and Network, with one explicit entry into the operational workbench.

The workbench retains the five role-oriented journeys because each maps directly to a contract authority or read model: public reading, owner lifecycle control, permissionless refresh, consumer binding and vintage audit. Contract states remain the source of truth; presentation never invents success from a receipt or local UI state.

The visual direction uses warm editorial space for public explanation and deep navy/electric blue for the on-chain workbench. A restrained GenLayer network motif communicates consensus without implying financial trading. Large serif headlines establish civic/public-data character; compact sans-serif controls preserve operational clarity.

Rejected patterns: a generic crypto dashboard, token/price imagery, a single dense admin form, cloned styling from the reference image, hidden documentation, wallet-first onboarding, and decorative state labels that are not authoritative contract values.
